# Phase 1：基礎數據平台閉環 — 開發計劃

**目標**：完成 API 接入 → 同步 → 入庫 → 基礎 Dashboard 展示
**預估工期**：6-8 週（1-2 名後端 + 1 名前端）
**狀態**：規劃中

---

## 1. 技術選型

| 層級 | 技術 |
|------|------|
| 後端 | FastAPI + Python 3.12 |
| ORM | SQLAlchemy 2.0 (async) |
| 數據庫 | PostgreSQL 16 (jsonb) |
| 緩存/隊列 | Redis 7 |
| 任務調度 | Celery + Celery Beat |
| 認證 | JWT (Access + Refresh) |
| 加密 | Fernet (cryptography) |
| 測試 | pytest + httpx + factory-boy |
| 容器化 | Docker + docker-compose |

## 3. 關鍵交付物

### 3.1 後端 API 端點

| 方法 | 路徑 | 說明 |
|------|------|------|
| POST | /api/v1/auth/login | 用戶登入 |

| POST | /api/v1/auth/refresh | 刷新 Token |
| GET | /api/v1/data-sources | 數據源列表 |
| POST | /api/v1/data-sources | 創建數據源 |
| GET | /api/v1/data-sources/{id} | 數據源詳情 |
| PUT | /api/v1/data-sources/{id} | 更新數據源 |
| DELETE | /api/v1/data-sources/{id} | 刪除數據源 |
| POST | /api/v1/data-sources/test | 測試連接 |
| GET | /api/v1/sync-jobs | 同步任務列表 |
| POST | /api/v1/sync-jobs | 創建同步任務 |
| GET | /api/v1/sync-jobs/{id} | 任務詳情 |
| PUT | /api/v1/sync-jobs/{id} | 更新任務 |
| DELETE | /api/v1/sync-jobs/{id} | 刪除任務 |
| POST | /api/v1/sync-jobs/{id}/trigger | 手動觸發同步 |
| GET | /api/v1/sync-jobs/{id}/runs | 任務執行記錄 |
| POST | /api/v1/query | 查詢圖表數據 |
| GET | /api/v1/dashboards | Dashboard 列表 |
| POST | /api/v1/dashboards | 創建 Dashboard |
| GET | /api/v1/dashboards/{id} | Dashboard 詳情 |
| PUT | /api/v1/dashboards/{id} | 更新 Dashboard |
| DELETE | /api/v1/dashboards/{id} | 刪除 Dashboard |
| POST | /api/v1/dashboards/{id}/publish | 發布 Dashboard |
| GET | /api/v1/audit-logs | 審計日誌列表 |

## 4. 驗收標準

- [ ] 用戶可以創建 REST API 數據源（Bearer Token / API Key）
- [ ] 點擊測試連接後，可以看到請求結果和返回樣例
- [ ] 用戶可以手動觸發同步
- [ ] 用戶可以設置定時同步（固定間隔 / Cron）
- [ ] 同步結果寫入數據庫，原始 JSON 有獨立存儲
- [ ] 字段映射生效，JSON 字段正確映射到結構化表
- [ ] 可以通過查詢 API 獲取聚合數據
- [ ] 用戶可以創建 Dashboard 並添加基礎圖表
- [ ] 圖表可以正確展示查詢結果
- [ ] 審計日誌記錄了關鍵操作
- [ ] 所有敏感憑證加密存儲、不落日誌
